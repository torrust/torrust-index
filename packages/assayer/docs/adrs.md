# The Assayer Record Register · `reg:assayer:decision-record-register`

This is the master register of the Assayer's decision records. It tracks the records that have landed and lists the ones that have not, and it holds nothing else: no summaries, no type index, no status column maintained by hand. What a record decides is in the record, and this document's whole job is to say which records exist and what each of their environments is called.

The set it registers is the derived one (`tab:assayer:record-set-master`), eighteen records under the naming schema (`dec:assayer:record-naming-schema-text`) — named by area, minting under that area, carrying no number that means anything. Records land in waves (`reg:assayer:decision-record-register`), and this register grows a block of rows per wave.

The hand-written index that stood here before is gone. It carried a per-type catalogue and a per-record status that the census found contradicting the records' own headers in eleven places (`reg:assayer:adr-status-contradictions`), which is the failure mode a hand-maintained register has and a tracked one does not: every row below is checked against the document it names, in both directions, on every run of the linter.

**Convention (What the tracking table asserts)** · `conv:assayer:record-register-tracking`

The table below is a tracking table in the positional register: its Head column names a label, its Document column names the file whose head must mint it, and the rows carry no labels of their own. The check runs both ways. A row naming a head the document does not mint is a failure, and a head the document mints that no row names is equally a failure — so the table cannot fall behind a record that gains an environment, and cannot outlive one that loses it.

Every environment of every landed record appears, not merely each record's identity head. That is what the relation means: the register tracks the set's contents, and a record's contents are its environments.
